# Assignment 6: Medians and Order Statistics & Elementary Data Structures

## Overview

This project implements selection algorithms and basic data structures using Python.

The assignment has two parts:

### Part 1: Selection Algorithms

- Median of Medians
- Randomized Quickselect
- Performance comparison using random, sorted, and reverse-sorted arrays

### Part 2: Elementary Data Structures

- Array
- Matrix
- Stack
- Queue
- Singly Linked List

## Files

- `selection_algorithms.py` - Selection algorithms
- `performance_analysis.py` - Execution time comparisons
- `elementary_data_structures.py` - Data structure implementations
- `test_data_structures.py` - Tests for both parts
- `Assignment_6_Report.docx` - Assignment report

## How to Run

Requires Python 3.

Run the selection algorithms:

```bash
python selection_algorithms.py
```

Run performance comparisons:

```bash
python performance_analysis.py
```

Run the data structures:

```bash
python elementary_data_structures.py
```

Run the tests:

```bash
python test_data_structures.py
```

## Results

Both selection algorithms returned the correct results.

Randomized Quickselect was faster in seven of the nine performance comparisons.

All six test groups passed successfully.

## Conclusion

This project demonstrates how selection algorithms and basic data structures work in Python. It also compares their performance and explains their practical applications.
